1ສິ່ງທີ່ຕ້ອງມີ

ລາຍການໝາຍເຫດ
Lightroom Classic 10 ຂຶ້ນໄປຈຳເປັນ. Lightroom ລຸ້ນຄລາວ (ທີ່ບໍ່ແມ່ນ Classic) ບໍ່ຮອງຮັບປລັກອິນ, ຈຶ່ງເຮັດ tether ບໍ່ໄດ້ເລີຍ.
macOS 11 ຂຶ້ນໄປປລັກອິນນີ້ໃຊ້ໄດ້ສະເພາະ Mac.
Xcode Command Line Toolsຕິດຕັ້ງຄັ້ງດຽວດ້ວຍ xcode-select --install. ໃຊ້ສຳລັບສ້າງໂປຣແກຣມຊ່ວຍໃສ່ລາຍນ້ຳ.
gPhoto2brew install gphoto2. ຈຳເປັນຖ້າຕໍ່ກ້ອງຜ່ານສາຍ USB ໂດຍກົງ.
ກ້ອງທີ່ສົ່ງພາບຜ່ານ FTP ໄດ້ (ບໍ່ບັງຄັບ)ສຳລັບຖ່າຍຜ່ານ Wi-Fi ໂດຍບໍ່ໃຊ້ສາຍ. ບໍ່ຕ້ອງໃຊ້ gPhoto2, FTP server ມີຢູ່ໃນປລັກອິນແລ້ວ (ເບິ່ງຫົວຂໍ້ 7).
ImageMagick (ບໍ່ບັງຄັບ)brew install imagemagick. ເປັນທາງເລືອກສຳຮອງສຳລັບໃສ່ລາຍນ້ຳ.
ບໍ່ຢາກຕິດຕັ້ງ gPhoto2?

ຍັງໃຊ້ງານໄດ້ຜ່ານໂໝດ Watched folder: ໃຫ້ແອັບຂອງຜູ້ຜະລິດກ້ອງ (Sony Imaging Edge, Canon EOS Utility, Nikon NX Tether) ເປັນຕົວດຶງພາບ, ແລ້ວປລັກອິນຈະຄອຍເບິ່ງໂຟນເດີນັ້ນແທນ.

2ການຕິດຕັ້ງ

  1. ເປີດ Terminal ແລ້ວແລ່ນສະຄຣິບຕິດຕັ້ງ 
    cd lightroom-tether-studio
./install.sh
    ສະຄຣິບຈະສ້າງ (compile) ໂປຣແກຣມຊ່ວຍໃສ່ລາຍນ້ຳ ແລ້ວເຊື່ອມປລັກອິນເຂົ້າໂຟນເດີປລັກອິນຂອງ Lightroom.
  2. ຕິດຕັ້ງ gPhoto2 (ຖ້າຍັງບໍ່ມີ ແລະ ຈະຕໍ່ກ້ອງຜ່ານ USB) 
    ./scripts/install-deps.sh --gphoto2
  3. ກວດໃນ Lightroom Classic

    ໄປທີ່ File→Plug-in Manager. ຕ້ອງເຫັນ Thaiymuan Production ຢູ່ໃນລາຍການ. ຖ້າບໍ່ເຫັນ, ກົດ Add ແລ້ວເລືອກໂຟນເດີ ThaiymuanProduction.lrplugin.

ຖ້າ Lightroom ບໍ່ເຫັນປລັກອິນ

ບາງຄັ້ງ Lightroom ບໍ່ອ່ານ symlink. ໃຫ້ຕິດຕັ້ງແບບສຳເນົາແທນດ້ວຍ ./install.sh --copy.

ຖອນການຕິດຕັ້ງ: ./install.sh --uninstall

3ຕັ້ງຄ່າກ້ອງກ່ອນໃຊ້ຄັ້ງທຳອິດ

ຂັ້ນຕອນນີ້ ສຳຄັນທີ່ສຸດ. ຖ້າຕັ້ງຜິດ, ກ້ອງຈະຕໍ່ບໍ່ຕິດ ຫຼື ບໍ່ສົ່ງພາບມາໃຫ້.

Sony A7 III, A7 IV, A7R V, A1 II, A6700, FX3

MENU → Setup (ໄອຄອນກະເປົ໋າ) → USB Connection → PC Remote
MENU → Setup → PC Remote Settings → Still Img. Save Dest. → PC+Camera
  • ຖ້າຕັ້ງເປັນ Auto / Mass Storage / MTP, ຄອມຈະເຫັນກ້ອງແຕ່ກ້ອງຈະບໍ່ສົ່ງພາບມາ.
  • ຖ້າ Save Dest. ເປັນ Camera Only, ກ້ອງຈະຖ່າຍໄດ້ແຕ່ບໍ່ສົ່ງໄຟລ໌ມາຄອມ.

Nikon

7ຮັບພາບຈາກກ້ອງຜ່ານ Wi-Fi (FTP)

ກ້ອງ Sony, Canon ແລະ Nikon ຫຼາຍລຸ້ນສົ່ງພາບຂຶ້ນ FTP server ຜ່ານ Wi-Fi ໄດ້. ປລັກອິນມີ FTP server ນ້ອຍໆ ຢູ່ໃນໂຕ (tsftpd), ຈຶ່ງຖ່າຍແບບບໍ່ມີສາຍໄດ້ ໂດຍບໍ່ຕ້ອງຕິດຕັ້ງ gPhoto2 ຫຼື ແອັບອື່ນ. ພາບທີ່ເຂົ້າມາຈະຖືກປ່ຽນຊື່, ນຳເຂົ້າ Lightroom ແລະ export ອັດຕະໂນມັດ ຄືກັບພາບຈາກສາຍ USB ທຸກຢ່າງ.

  1. ຕໍ່ Wi-Fi ດຽວກັນກ້ອງ ແລະ Mac ຕ້ອງຢູ່ໃນເຄືອຂ່າຍ Wi-Fi ດຽວກັນ (ຫຼື ໃຫ້ກ້ອງຕໍ່ hotspot ດຽວກັບ Mac).
  2. ເລືອກແຫຼ່ງພາບແຖບ 1 · ກ້ອງ → ແຫຼ່ງພາບ → ກ້ອງຜ່ານ Wi-Fi (FTP). ກອບ ໃສ່ຄ່າເຫຼົ່ານີ້ໃນກ້ອງ ຈະສະແດງຂຶ້ນ.
  3. ໃສ່ຄ່າໃນກ້ອງ (ຄັ້ງດຽວ)ເປີດເມນູ FTP ຂອງກ້ອງ ແລ້ວພິມຄ່າຕາມກອບນັ້ນ (ເບິ່ງຕາຕະລາງຂ້າງລຸ່ມ). ເປີດການສົ່ງອັດຕະໂນມັດທຸກຄັ້ງທີ່ຖ່າຍ (auto transfer) ໄວ້ນຳ.
  4. ເລືອກໂຟນເດີປາຍທາງ ແລ້ວກົດ ເລີ່ມຖ່າຍສະຖານະຈະຂຶ້ນ "ພ້ອມແລ້ວ — ກຳລັງລໍຖ້າພາບຈາກກ້ອງຜ່ານ Wi-Fi ທີ່ …". ເມື່ອກ້ອງເຂົ້າສູ່ລະບົບ ສະຖານະຈະບອກວ່າກ້ອງເຊື່ອມຕໍ່ແລ້ວ.
  5. ຄັ້ງທຳອິດ: ກົດ AllowmacOS ອາດຖາມວ່າຈະໃຫ້ tsftpd ຮັບການເຊື່ອມຕໍ່ຈາກເຄືອຂ່າຍບໍ່. ກົດ Allow, ບໍ່ດັ່ງນັ້ນກ້ອງຈະເຊື່ອມຕໍ່ບໍ່ໄດ້.

ສົ່ງທຸກໄຟລ໌ທີ່ export ແລ້ວ ຂຶ້ນເຊີບເວີ FTP ໂດຍກົງ ເຊັ່ນ ເຊີບເວີຂອງລູກຄ້າ, ເວັບໄຊຂອງທ່ານ ຫຼື ຮ້ານອັດຮູບ. ໄຟລ໌ຍັງຖືກເກັບໄວ້ໃນໂຟນເດີ export ຄືເກົ່າ. ຕັ້ງຄ່າໄດ້ທັງໃນສ່ວນ Deliver ຂອງ Export ແລະ ໃນໜ້າຕ່າງ Export Profiles….

  1. ໝາຍຖືກ ອັບໂຫຼດຂຶ້ນເຊີບເວີ FTP
  2. ໂປໂຕຄອນFTPS (ເຂົ້າລະຫັດ) ຖ້າເຊີບເວີຮອງຮັບ (ອາດເອີ້ນວ່າ "FTP over TLS"), ບໍ່ດັ່ງນັ້ນ FTP.
  3. ເຊີບເວີ, ຊື່ຜູ້ໃຊ້ ແລະ ລະຫັດຜ່ານເຊັ່ນ ftp.example.com (ບໍ່ຕ້ອງໃສ່ ftp://). ລະຫັດຜ່ານເກັບໄວ້ໃນ keychain ຂອງ macOS, ບໍ່ຢູ່ໃນ Profile ແລະ ບໍ່ຂຶ້ນໃນ log.
  4. ໂຟນເດີເທິງເຊີບເວີເຊັ່ນ /{date} ຫຼື /ລູກຄ້າ/{year}/{date}. ໂຟນເດີທີ່ຍັງບໍ່ມີຈະຖືກສ້າງໃຫ້.
  5. ກົດ ທົດສອບການເຊື່ອມຕໍ່ເຂົ້າສູ່ລະບົບ ແລະ ກວດໂຟນເດີ ໂດຍບໍ່ອັບໂຫຼດຫຍັງ.

ໃນການຕັ້ງຄ່າຂັ້ນສູງ: ພອດ (ປົກກະຕິ 21) ແລະ ໂໝດ Passive (ເປີດໄວ້, ເວັ້ນແຕ່ເຊີບເວີບອກໃຫ້ໃຊ້ active mode).

ไม่อยากติดตั้ง gPhoto2?

ยังใช้งานได้ผ่านโหมด Watched folder โดยให้แอปของผู้ผลิตกล้อง (Sony Imaging Edge, Canon EOS Utility, Nikon NX Tether) เป็นตัวดึงภาพ แล้วปลั๊กอินคอยดูโฟลเดอร์นั้นแทน

2ติดตั้ง

  1. เปิด Terminal แล้วรันสคริปต์ติดตั้ง 
    cd lightroom-tether-studio
./install.sh
    สคริปต์จะคอมไพล์โปรแกรมช่วยใส่ลายน้ำ แล้วเชื่อมปลั๊กอินเข้าโฟลเดอร์ปลั๊กอินของ Lightroom
  2. ติดตั้ง gPhoto2 (ถ้ายังไม่มี และจะต่อกล้องผ่าน USB) 
    ./scripts/install-deps.sh --gphoto2
  3. ตรวจใน Lightroom Classic

    ไปที่ File→Plug-in Manager ต้องเห็น Thaiymuan Production ในรายการ ถ้าไม่เห็น ให้กด Add แล้วเลือกโฟลเดอร์ ThaiymuanProduction.lrplugin

ถ้า Lightroom มองไม่เห็นปลั๊กอิน

บางครั้ง Lightroom ไม่อ่าน symlink ให้ติดตั้งแบบคัดลอกแทนด้วย ./install.sh --copy

ถอนการติดตั้ง: ./install.sh --uninstall

6โหมด Watched folder

ใช้เมื่อกล้องต่อ USB โดยตรงไม่ได้ หรืออยากใช้แอปของผู้ผลิต (Imaging Edge Desktop, EOS Utility, NX Tether) หรือส่งภาพผ่าน Wi-Fi / FTP โหมดนี้ ไม่ได้ด้อยกว่า ทุกภาพยังได้การตั้งชื่อ preset และ auto-export เหมือนกันทุกอย่าง

  1. ตั้งแอปของผู้ผลิตให้บันทึกภาพลงโฟลเดอร์หนึ่ง เช่น ~/Pictures/Incoming
  2. Sourceในแท็บ Camera เลือก Watched folder (vendor tether app, Wi-Fi or FTP)
  3. Watch folderเลือกโฟลเดอร์เดียวกับที่แอปบันทึกภาพลง
  4. Check every / File typesค่าเริ่มต้นใช้ได้เลย ถ้าส่งผ่าน Wi-Fi หรือ FTP ที่ช้า ให้เพิ่ม Check every เป็น 2–3 วินาที
  5. Incoming files (แท็บ Files)
    • Move into the destination folder — ย้ายไฟล์ออกจากโฟลเดอร์ที่ดู
    • Copy into the destination folder — คัดลอก ต้นฉบับยังอยู่
    • Leave where they are — ไม่ย้าย นำเข้า Lightroom จากที่เดิม
โฟลเดอร์ว่างและแยกกัน
  • ถ้า โฟลเดอร์ปลายทางอยู่ภายในโฟลเดอร์ที่เฝ้าดู รายการตรวจจะขึ้น ✕ และกด เริ่มถ่าย ไม่ได้ เพื่อป้องกันไม่ให้ไฟล์ถูกคัดลอกซ้ำไม่หยุด
  • ถ้า โฟลเดอร์ที่เฝ้าดูมีไฟล์เก่าอยู่ จะขึ้น ! พร้อมจำนวนไฟล์ เพราะไฟล์เหล่านั้นจะถูกนำเข้า แนะนำให้ใช้โฟลเดอร์ว่าง
  • เมื่อเปลี่ยนแหล่งภาพเป็น Watched folder ไฟล์ที่เข้ามา จะเปลี่ยนจาก "ย้าย" เป็น "คัดลอก" เอง เพื่อให้ต้นฉบับยังอยู่ เปลี่ยนได้ในการตั้งค่าขั้นสูง

7รับภาพจากกล้องผ่าน Wi-Fi (FTP)

กล้อง Sony, Canon และ Nikon หลายรุ่นส่งภาพขึ้น FTP server ผ่าน Wi-Fi ได้ ปลั๊กอินมี FTP server เล็ก ๆ ในตัว (tsftpd) จึงถ่ายแบบไร้สายได้ โดยไม่ต้องติดตั้ง gPhoto2 หรือแอปอื่น ภาพที่เข้ามาจะถูกเปลี่ยนชื่อ นำเข้า Lightroom และ export อัตโนมัติ เหมือนภาพจากสาย USB ทุกอย่าง

  1. ต่อ Wi-Fi เดียวกันกล้องและ Mac ต้องอยู่ในเครือข่าย Wi-Fi เดียวกัน (หรือให้กล้องต่อ hotspot เดียวกับ Mac)
  2. เลือกแหล่งภาพแท็บ 1 · กล้อง → แหล่งภาพ → กล้องผ่าน Wi-Fi (FTP) กรอบ ใส่ค่าเหล่านี้ในกล้อง จะแสดงขึ้น
  3. ใส่ค่าในกล้อง (ครั้งเดียว)เปิดเมนู FTP ของกล้อง แล้วพิมพ์ค่าตามกรอบนั้น (ดูตารางด้านล่าง) และเปิดการส่งอัตโนมัติทุกครั้งที่ถ่าย (auto transfer) ไว้ด้วย
  4. เลือกโฟลเดอร์ปลายทาง แล้วกด เริ่มถ่ายสถานะจะขึ้น "พร้อมแล้ว — กำลังรอภาพจากกล้องผ่าน Wi-Fi ที่ …" เมื่อกล้องเข้าสู่ระบบ สถานะจะบอกว่ากล้องเชื่อมต่อแล้ว
  5. ครั้งแรก: กด AllowmacOS อาจถามว่าจะให้ tsftpd รับการเชื่อมต่อจากเครือข่ายไหม กด Allow ไม่เช่นนั้นกล้องจะเชื่อมต่อไม่ได้

  • ภาพจะถูกนำเข้า ก็ต่อเมื่อโอนครบแล้ว ภาพที่โอนไม่สำเร็จจะไม่เข้า Lightroom
  • ถ้าชื่อไฟล์ซ้ำ จะต่อท้าย -1, -2… ไม่มีการเขียนทับภาพเดิม
  • ถ้า FTP server หยุดกลางคัน ปลั๊กอินจะเปิดใหม่เอง
  • ใน แสดงการตั้งค่าขั้นสูง เปลี่ยนพอร์ตและโฟลเดอร์ inbox ได้ ถ้าเปลี่ยนพอร์ต ต้องเปลี่ยนในกล้องด้วย

  • FTP ธรรมดาไม่เข้ารหัส ใช้ใน Wi-Fi ของคุณเองหรือ hotspot อย่าใช้ Wi-Fi สาธารณะ
  • ไฟล์ RAW ขนาดใหญ่ใช้เวลาโอนผ่าน Wi-Fi หลายวินาทีต่อภาพ ถ้าต้องการให้ลูกค้าเห็นเร็ว ตั้งกล้องให้ส่งเฉพาะ JPEG
  • ก่อนรับงานที่มีค่าจ้าง ให้ทดสอบกับกล้องและเครือข่ายที่จะใช้จริงก่อน

หน้าต่าง Export Profiles: 3 ขั้นตอน

  1. เลือกหรือสร้าง profileสร้างใหม่… · ทำสำเนา… · เปลี่ยนชื่อ… · ลบ ชื่อที่ซ้ำกับ profile ที่มีอยู่จะไม่ถูกรับ เพื่อไม่ให้เขียนทับ
  2. ปรับค่ามีบรรทัดสรุปค่าของ profile สั้น ๆ ให้เห็น
  3. บันทึกถ้ายังไม่ได้บันทึก จะขึ้น "● มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก" เมื่อบันทึกแล้ว จะขึ้น "✓ บันทึกทุกอย่างแล้ว"

11ส่งไฟล์ขึ้นคลาวด์ (Deliver)

ส่วน Thaiymuan Production — Deliver จะคัดลอกทุกไฟล์ที่ export เสร็จแล้ว เข้าโฟลเดอร์ที่แอปคลาวด์ซิงก์อยู่ (Google Drive, Dropbox, iCloud Drive) แอปคลาวด์จะอัปโหลดเอง จึงไม่ต้องล็อกอินอะไรในปลั๊กอิน

  1. ติดตั้งและล็อกอินแอปคลาวด์เช่น Google Drive for desktop หรือ Dropbox บน Mac
  2. Detectedเลือกโฟลเดอร์คลาวด์ที่ปลั๊กอินพบในเครื่อง หรือกด Choose… ในช่อง Folder
  3. Subfolderใช้ token {date} {year} {orig} ได้ เช่น ลูกค้า/{date}
ข้อจำกัด

ปลั๊กอินยืนยันได้แค่ว่าไฟล์ถูกคัดลอกเข้าโฟลเดอร์คลาวด์แล้วเท่านั้น การอัปโหลดขึ้นเซิร์ฟเวอร์เป็นหน้าที่ของแอปคลาวด์ ให้ตรวจสถานะในแอปนั้น

อัปโหลดขึ้นเซิร์ฟเวอร์ FTP / FTPS

ส่งทุกไฟล์ที่ export แล้ว ขึ้นเซิร์ฟเวอร์ FTP โดยตรง เช่น เซิร์ฟเวอร์ของลูกค้า เว็บไซต์ของคุณ หรือร้านอัดรูป ไฟล์ยังถูกเก็บในโฟลเดอร์ export เหมือนเดิม ตั้งค่าได้ทั้งในส่วน Deliver ของ Export และในหน้าต่าง Export Profiles…

  1. ติ๊ก อัปโหลดขึ้นเซิร์ฟเวอร์ FTP
  2. โปรโตคอลFTPS (เข้ารหัส) ถ้าเซิร์ฟเวอร์รองรับ (อาจเรียกว่า "FTP over TLS") ไม่เช่นนั้นใช้ FTP
  3. เซิร์ฟเวอร์ ชื่อผู้ใช้ และรหัสผ่านเช่น ftp.example.com (ไม่ต้องใส่ ftp://) รหัสผ่านเก็บใน keychain ของ macOS ไม่อยู่ใน Profile และไม่ขึ้นใน log
  4. โฟลเดอร์บนเซิร์ฟเวอร์เช่น /{date} หรือ /ลูกค้า/{year}/{date} โฟลเดอร์ที่ยังไม่มีจะถูกสร้างให้
  5. กด ทดสอบการเชื่อมต่อเข้าสู่ระบบและตรวจโฟลเดอร์ โดยไม่อัปโหลดอะไร

7Camera over Wi-Fi (FTP)

Many Sony, Canon and Nikon cameras can send photos to an FTP server over Wi-Fi. The plug-in has a small FTP server built in (tsftpd), so you can shoot without a cable and without installing gPhoto2 or any other app. Arriving photos are renamed, imported and auto-exported exactly like USB captures.

  1. Same Wi-FiThe camera and the Mac must be on the same Wi-Fi network (or the camera joins the same hotspot as the Mac).
  2. Choose the sourceTab 1 · Camera → Source → Camera over Wi-Fi (FTP). An Enter these in the camera box appears.
  3. Enter the settings in the camera (once)Open the camera's FTP menu and type in the values from that box (see the table below). Also turn on automatic transfer after every shot.
  4. Choose a destination and press Start CaptureThe status reads "Live — waiting for photos from the camera over Wi-Fi at …". Once the camera logs in, the status says it is connected.
  5. First time: press AllowmacOS may ask whether tsftpd may accept incoming network connections. Press Allow, or the camera cannot connect.

How photos arrive

  • The camera uploads into <Destination>/FTP Inbox. Each photo is moved into the destination and renamed straight away, so the inbox stays nearly empty.
  • A photo is imported only once it has fully arrived. Interrupted transfers never reach Lightroom.
  • Clashing names get -1, -2… appended; nothing is ever overwritten.

  • Large RAW files take several seconds each over Wi-Fi. If the client needs to see shots quickly, have the camera send JPEG only.
  • Before a paid job, test with the actual camera and network you will use.

With a fixed name like A7IV alone, every file gets the same name and is suffixed -1, -2 and so on. Use something like A7IV-{seq:4} instead.

Original name mode

After reformatting a card, or with two camera bodies, numbers can repeat. Use Date and sequence for important jobs. The plug-in never overwrites an existing file.

Exported files always keep the source file's name, e.g. DSC00123.ARW → DSC00123.jpg. No need to set it twice.

11Cloud delivery (Deliver)

The Thaiymuan Production — Deliver section copies every finished export into a folder your cloud app keeps in sync (Google Drive, Dropbox, iCloud Drive). The cloud app does the uploading, so there's nothing to sign in to in the plug-in.

  1. Install and sign in to the cloud appe.g. Google Drive for desktop or Dropbox on the Mac.
  2. DetectedPick a cloud folder the plug-in found, or press Choose… next to Folder.
  3. SubfolderTokens {date} {year} {orig} work here, e.g. Client/{date}.
Limitation

The plug-in can only confirm the file was copied into the cloud folder. Uploading to the server is the cloud app's job; check its status there.

Upload to an FTP / FTPS server

Send every finished export straight to an FTP server: a client's server, your website, or a print lab. Files are still kept in the export folder. Set it up in the Deliver section of the Export dialog or in the Export Profiles… window.

  1. Tick Upload to an FTP server
  2. ProtocolFTPS (encrypted) when the server supports it (also called "FTP over TLS"), otherwise FTP.
  3. Server, user name and passwordFor example ftp.example.com (no ftp://). The password is kept in the macOS keychain: never in the profile, and never in the log.
  4. Remote folderFor example /{date} or /clients/{year}/{date}. Missing folders are created.
  5. Press Test ConnectionLogs in and checks the folder without uploading anything.

Advanced settings: Port (usually 21) and Passive mode (leave on unless the server says "active mode").

While tethering

Auto-export uploads too. If an upload fails, no dialog pops up to interrupt the shoot: the message appears in the capture window's status line instead, and the files are safe in the export folder. SFTP is not supported.

12Interval shooting

Camera tab → Shutter, choose Fire automatically every N seconds:

First tick ☑ Show advanced settings on tab 1 · Camera; this is an advanced setting.

Every: [10] seconds, [0] frames
  • frames = 0 means keep shooting until you press Stop.
  • The camera must be able to focus or it won't fire. Use MF (manual focus) for time-lapse.
  • Each frame takes a few seconds to transfer. Too short an interval makes the timing drift.
Recommended

Set frames = 0 and press Stop Capture yourself once you have enough frames. In the current version, a frame limit combined with Reconnect… switched on may start a new series by itself.

The default is Wait for me to press the shutter (manual). If you don't change it, nothing is different.
